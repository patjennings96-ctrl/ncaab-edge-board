The sheet's formulas

How Cal's model works

Model 1 · raw efficiency

base = possessions × eff. possession ratio proj 1 = base × off. eff proj 2 = base × (2 − opp def. eff) proj 3 = proj 1 × opp def. eff score = average(proj 1, proj 2, proj 3)

Offensive and defensive efficiency are points scored and allowed per possession. Effective possession ratio is (possessions − turnovers + offensive rebounds) ÷ possessions.

Model 2 · adjusted ratings

o = AdjO / 100, d = opp AdjD / 100 proj 1 = AdjT × o proj 2 = o × AdjT × d proj 3 = o × min(both AdjT) × d score = average(proj 1, proj 2, proj 3)

Adjusted offense, defense and tempo, in points per 100 possessions. The sheet used KenPom.

When it bets

  • Spread: home side if both models' spread value is +5 or more; road side if both are −5 or less.
  • Total: each day, Model 2's total values are shifted by the slate's average. Over if Model 1 and adjusted Model 2 are both +7 or more; under if both are −7 or less.
  • Units: flat 1 unit at −110; a win is +1, a loss −1.1.
  • Home court: 3 points added to each model's margin (home +1.5, road −1.5), so totals don't change. Neutral-site games get none. The original sheet had no home-court term.

Where the data comes from here

  • The sheet pulled TeamRankings and KenPom pages and a DraftKings line scraper. Those sites block automated pulls, so this version computes the same stats from ESPN box scores and uses the Edge Board's lines (The Odds API).
  • Model 1's inputs come from this season's games once a team has played 3. Before that, last season's numbers are used.
  • Model 2 uses a KenPom export when one is saved to data/external/kenpom/teams.csv, otherwise the Edge Board's adjusted ratings.
